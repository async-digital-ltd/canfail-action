# What the action installs, and nothing else: canfail, and the two packages it
# asks for, whose behaviour is part of every verdict it gives. didrun decides
# whether a run printed the evidence that it ran, and restore-verified puts a
# planted file back and checks it came back. canfail declares both with a floor
# and no ceiling, so with canfail pinned alone a new release of either could
# grade the same declaration differently under the same canfail version.
#
# Installed with --require-hashes, so pip refuses any package this file does not
# name with a hash, and any archive whose hash is not the one written here.
#
# To move one, change its version and both of its hashes together, from
# `curl -s https://pypi.org/pypi/<name>/<version>/json | jq -r '.urls[] |
# .filename + " " + .digests.sha256'`, check the new release's own dependencies
# are still only these, and release a new version of the action.
